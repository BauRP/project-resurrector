# Два ТЗ MULTI-CAM POV: что означает «100%»

Рабочая ветка: `chatgpt/independent-preview-20261023`. Main не менять без явного разрешения.

## Две независимые шкалы

1. **Индекс программного покрытия (79 сценариев)**: в `TWO_SPEC_MEASURED_PROGRESS.md`.
   За каждый сценарий: 1 = прямой исполняемый тест основной программной логики, 0.5 = частичная проверка, 0 = не подтверждено. Это **не процент реализованных функций**. Даже 79/79 не гарантирует полную готовность.
2. **Приёмка разработки по двум ТЗ**: «готово» можно заявить только после выполнения **всех** пунктов ниже; нельзя подменить их ростом индекса.

## Критерии окончания программной разработки

- [ ] Все исходные требования ТЗ «Обнаружение камер и проверка» закрыты кодом, без заглушек, объявленных поддержкой.
- [ ] Все исходные требования ТЗ «Сделать раскладушку / мультидисплей» закрыты кодом: book, flip, tri-fold, tabletop, внешние и раздельные экраны, поворот, resize, safe insets и клавиатура.
- [ ] Camera2 и WebView не открывают один сенсор конкурентно; обратная передача владельца подтверждена; запоздалые ответы не меняют актуальную сессию.
- [ ] Запись: успешное начало кодировщика, остановка, сохранение, чтение файла, воспроизведение, MP4-метаданные и отличение ошибки/частичного файла от полного успеха проверены end-to-end.
- [ ] При fold/Activity recreation во время записи не объявляется ложная непрерывность; сохранившиеся данные и причина прерывания не теряются, самопроизвольного рестарта нет.
- [ ] Несколько телефонов: сопряжение, независимые peer-идентичности, отказ одного peer, переподключение, START/STOP без дубликатов и отмена/таймаут подтверждены комплексными тестами.
- [ ] Две камеры: обе видеодорожки реально существуют и сохраняются; несинхронные записи не выдаются за покадрово синхронизированные.
- [ ] Редактор: мультитрековый предпросмотр, восстановление проекта/курсора/прокрутки, экспорт, возвращение после fold без потери данных проверены.
- [ ] Ошибки в последних автоматических проверках устранены; полный CI (тесты, TypeScript, Android APK/AAB) успешен на финальном commit SHA.
- [ ] Для каждого из 79 пунктов записано: путь к производственному коду, ссылка на исполняемый тест, фактический результат и оставшиеся ограничения. Нет известных критических и блокирующих дефектов.

## Отдельная аппаратная приёмка

Только после программной разработки: реальные физические сенсоры, устройства разных OEM, реальные fold/tri-fold/cover экраны, устойчивость 4K/FPS, тепловые и акустические режимы, длительная запись, сеть и прерывания. Успех CI/эмулятора **не равен** прохождению этих проверок.

## Правило отчёта

Всегда публиковать отдельно:
- Индекс автоматизированного покрытия (камеры/раскладушки/общий).
- Подтверждённые реализованные функции, не прошедшие проверки, и блокирующие проблемы.
- Последний SHA и результат CI, без округления/искусственного приближения к 100.
- Запрет писать «вся работа окончена», пока критерии программной приёмки не выполнены.
