# Сборка APK через GitHub

1. В Lovable откройте **Connectors → GitHub** и подключите репозиторий.
2. После подключения каждое изменение автоматически отправляется в GitHub, и запускается сборка «Android APK».
3. Откройте репозиторий на GitHub → вкладка **Actions** → последний запуск «Android APK».
4. Дождитесь зелёной галочки (около 5–8 минут), внизу страницы в разделе **Artifacts** скачайте `multi-cam-pov-apk`.
5. Распакуйте архив, перенесите `app-debug.apk` на телефон и установите (разрешите установку из неизвестных источников).

Запустить сборку вручную: Actions → «Android APK» → **Run workflow**.
