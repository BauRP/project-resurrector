# Multi-Cam Studio / POV — телефонный экран, камера, редактор и сборка APK

## 1. Экран строго 9:16
- Всё приложение рендерится в контейнере с пропорцией 9:16 по центру окна (высота = высота экрана, ширина = высота × 9/16), без декоративного корпуса.
- На реальном телефоне контейнер занимает весь экран. Нижнее меню, модальные окна и шторки ограничены этим контейнером.

## 2. Камера
- Панель возможностей устройства: при запуске опрашиваются доступные разрешения, частоты кадров и кодеки. Неподдерживаемые варианты становятся неактивными, а при попытке их выбрать показывается уведомление о защите от перегрева.
- Выбор разрешения / FPS / кодека; режимы Normal, Slow‑mo 120/240 (только если поддерживается), Time‑lapse, Hyperlapse (запись с прореживанием кадров).
- Профили LOG / FLAT / Direct Log — тоновая кривая в реальном времени поверх превью и при записи (через canvas).
- Ручные выдержка, ISO, фокус (применяются к камере, если она это поддерживает; иначе ползунок заблокирован с пояснением).
- Выбор микрофона (включая USB/Bluetooth из списка устройств), VU/PPM-индикаторы на основе реального RMS.
- Пауза/продолжение записи: фрагменты сохраняются локально и склеиваются в один клип.
- Мониторинг: счётчик пропущенных кадров, температура/тепловое состояние (из нативного модуля; в браузере — «недоступно»).
- Быстрое переключение CAM 1/2/3, сетки (трети, перекрестие).

## 3. Редактор
- Таймлайн с кнопками масштаба +/−, покадровые шаги, обрезка; воспроизведение и таймкод строго с 00:00.
- Кнопка «Создать офлайн‑субтитры» с подсветкой состояния; повторное нажатие скрывает/фиксирует без зависаний.
- Тексты и субтитры перетаскиваются по превью; нажатие открывает окно шрифта/размера/цвета/фона.
- Скорость (0.25×–4×) и реверс.
- Треки: превью Cam 1–3, перетаскивание клипов и аудио по таймлайну, реальные волновые формы из записанного звука, отделение аудио от видео, кнопки mute звука/видео на трек, добавление и удаление со сдвигом.
- Логика эффектов: без выделения — скорость, цвет, масштаб, позиция X и прозрачность применяются ко всем трекам; долгое нажатие на клип выделяет его и изменения идут только в этот клип (с явным индикатором «Глобально / Клип»).

## 4. Нативный Android-модуль и сборка
- Android-проект (Capacitor, SDK 35, Gradle, AndroidManifest с правами камеры, микрофона, хранилища).
- Нативный Kotlin-плагин «MultiCamNative»: опрос Camera2 / StreamConfigurationMap / CamcorderProfile, запись через MediaRecorder в т.ч. high-speed 120/240, тепловой статус PowerManager, список аудиовходов AudioManager. Веб-часть автоматически использует плагин на телефоне и браузерные средства в превью.
- `.github/workflows/android_build.yml`: сборка debug APK при каждом push, APK доступен как артефакт во вкладке Actions.
- Пошаговая инструкция на русском: подключить GitHub, дождаться сборки, скачать APK.

## Ограничения
- Нативный модуль нельзя проверить здесь — только после сборки APK на телефоне. Веб-часть будет проверена в превью.
- В браузере 120/240 fps, температура и ручной ISO доступны только если их отдаёт устройство; иначе элементы честно блокируются.

## Технические детали
- Контейнер: `.app-shell` → `aspect-ratio: 9/16; height: 100dvh; max-width: 100vw`, `position: fixed` элементы переводятся на `absolute` внутри shell (`transform` на shell создаёт containing block).
- Возможности в вебе: `MediaStreamTrack.getCapabilities()`, `MediaRecorder.isTypeSupported`, `enumerateDevices`; RMS через `AnalyserNode`; пропуски кадров через `requestVideoFrameCallback`.
- Склейка фрагментов: MediaRecorder pause/resume + объединение Blob; LOG-кривая — canvas `captureStream()`.
- Нативный плагин: `android/app/src/main/java/.../MultiCamNativePlugin.kt`, регистрация в `MainActivity`, TS-обёртка через `registerPlugin`.
- CI: JDK 21, `bun install`, `bun run build`, `npx cap sync android`, `./gradlew assembleDebug`, `upload-artifact`.
